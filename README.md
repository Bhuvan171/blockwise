# Blockwise

Decision page for **Blockwise**, a risk-aware planner for hotel and flight inventory commitments (prepaid blocks, refundable allotments, buy as needed) within a budget. Built for TBO VoyageHack 4.0, topic "Automate Inventory Optimization".

Live site: https://bhuvan171.github.io/blockwise/

This branch holds only the built static page (`index.html`) and its overview film (`blockwise-overview.mp4`, poster `blockwise-overview-poster.jpg`). Source: the `main` branch. The portfolio planner shown on the page is synthetic; the proof sections use public hotel booking data (António, Almeida & Nunes, 2019) and SingStat tables M550001 and M550081 (Singapore Open Data Licence).
